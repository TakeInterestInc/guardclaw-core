# Two-minute feedback trial

Use synthetic data only. No automatic submission, account, telemetry or external form. Copy the template into a local note; decide separately whether and how to share it. Avoid personal/private project information.

1. Find a decision and explain its trade-off in your own words.
2. Inspect its task and identify the strongest evidence or the missing check.
3. Find one stale or unknown task and name the next useful action.
4. Compare this experience with native dots Activity plus the quick-start guide.

## Template

- App/browser and approximate screen size (optional, no identifying details):
- What question were you trying to answer?
- What did you understand in the first 30 seconds?
- Which label or action was unclear?
- Could you distinguish proposed, implemented and reported verified?
- Did the observation time/source help you trust or question a claim?
- Did recommendation, trade-off and disagreement improve the decision?
- Was the native UI plus the guide enough? What extra value did this add?
